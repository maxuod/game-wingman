# 首次 DeepSeek 对局测试（¥10 上限）

2026-09-24。本地测试版固定使用 `deepseek-flash`。当前识别 TFT 可见的阶段、金币、生命、等级和名称；尚未验证真实对局准确性，也没有接入战术攻略建议。

## 启动

1. 退出旧版 Game Wingman，运行 `release/baseline-preview/Game Wingman-win32-x64/Game Wingman.exe`，保留整个目录。
2. 进入测试对局后，在主窗口选择**实际游戏窗口**，点击“开始读取”，确认实时视频正确。
3. 打开“资料与设置 → AI 识别”。已有 DeepSeek 密钥会沿用；勾选“允许 AI 请求”并保存。
4. 点击“开始本次跟进”，在窗口名称、模型和预算确认框中开始本次发送。返回主界面，点击“显示浮窗”。仅开始本机读取不会发送给模型。
5. 结束时点击“停止跟进”或“暂停读取”。核对设置中的请求数、保守核算费用及平均响应时间。费用账本在 `%APPDATA%\Game Wingman\deepseek-baseline-budget.jsonl`。

## 视频和时延

- 本机视频请求约 15 fps，上限 30 fps；实际取决于系统和源窗口。无音频采集。
- 本机每秒取一张候选帧。画面有变化时模型请求最短间隔 5 秒，变化较小时 15 秒复查；每次只发当前压缩图片，不发整段视频或重复历史。
- 一次只等待一个模型请求，不排队积压。单次实时请求超时 10 秒；识别结果注明画面时间。总延迟包含抽样等待、网络和模型处理，不承诺逐帧即时响应。
- 连续三次缺失足够 TFT HUD、窗口画面停止更新、请求失败、切换窗口、暂停、修改设置或退出都会停止自动发送。最长 60 分钟 / 720 次；重新开始须手动开启，预算不重置。

## ¥10 如何执行

预算覆盖本测试版桌面发出的全部 DeepSeek 请求，包括实时识别、手动单帧和文字连接测试。其他提供方和模型在本测试版被锁定，没有自动切换或重试。之前的基准测试、其他应用和独立开发 CLI 不属于这份账本；它不是账户级扣费开关。

使用整数微元（1 元 = 1,000,000 微元）记账。按[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/?article_id=article_1779470751466_8)的高峰无缓存档保守核算：每百万输入 ¥2、输出 ¥8，不扣缓存或闲时优惠。因此显示的是费用保守核算值，不是 DeepSeek 实际账单。

每次请求前，按完整 1 Mi token 上下文加本程序最多 1,024 输出 token 预留 **¥2.105344**，先写入本地账本并同步到磁盘，才发请求。这里故意使用模型最大上下文，不靠图片 token 估算作为上限依据。API 返回有效用量后按用量核算，释放剩余预留。正常短字段识别远低于预留额；预留不是实际扣款。[模型上下文](https://api-docs.deepseek.com/quick_start/pricing/)和[图片用量规则](https://api-docs.deepseek.com/guides/vision/)为预算依据，价格核查于 2026-09-24。

若已核算金额 + 未确认预留 + 下一次预留超过 ¥10，则发送前停止，故可能提前停止于 ¥10 以下。超时、取消、截断、缺失用量或崩溃不证明提供方未收费，保留整笔预留；重启仍计入。账本损坏或写入失败会锁定后续请求。应用没有“重新开始即清零”按钮。不要删除账本来续跑，也不要并行运行其他版本来共用本次额度。若官方改价，应先更新并重新核验预算规则。

账本只记录请求 ID、时间、token、响应耗时和预留/核算事件，不保存截图、提示词、昵称或密钥。字段变化记录保留在当前会话内存；核对真实准确性仍需人工对照游戏画面。

## 本轮关注点

观察窗口预览是否正确、阶段/金币/生命/等级是否读对、未知值是否保留、浮窗是否过时、网络中断是否停止，以及 30 分钟累计请求数/核算金额。普通自动化测试只使用合成窗口、假密钥和模拟响应，不能代替这次真实游戏测试。
