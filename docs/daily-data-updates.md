# 启动检查 TFT 补丁与阵容排名

2026-09-24，用户确认范围是 TFT 补丁和资料版本，不包含 Wingman 软件本体下载安装。最新 Windows 包为 `release/daily-data-preview/Game Wingman-win32-x64/Game Wingman.exe`，继续使用原来的加密凭据和累计 DeepSeek ¥10 预算。

每天按电脑本地日期首次启动时，程序读取 [Riot 官方更新目录](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/)及匹配的补丁公告，确认已发布补丁和公告中的热修标记。不会把预告、相关链接、视频标题或 Data Dragon 资源版本当成已经生效的 TFT 补丁。现有真实来源核对为 18.3B。

阵容排名按以下条件自动刷新：本地尚无成功缓存、进入新的一天、上次检查超过 6 小时，或官方补丁/公告正文发生变化。同日重复启动且缓存有效时直接使用缓存。程序持续运行时每分钟仅在本地检查是否到期，到期后才联网；关闭时不在后台运行，也不创建操作系统计划任务。手动“刷新统计”可立即重查。

资料缓存在应用数据目录 `Game Wingman/tft-public-data-v1.json`，包括公开阵容事实、官方版本摘要/内容指纹、检查和尝试时间、排名比较结果。通过临时文件再重命名写入；损坏或格式不符时回退到内置资料。没有截图、玩家信息、个人装备清单或 API Key。此文件与金额账本分开，删除或损坏资料缓存不会重置 ¥10 账本。

每次成功刷新与上次同补丁快照比较，分别计算前四率和吃鸡率的排名升降、百分点差、新增和移出阵容。卡片箭头随当前排序切换，说明中标明比较基准时间。新补丁重新建立基准，不跨补丁混算升降。更新失败保留旧数据及其原日期，并将该来源的自动重试延后 1 小时；重启不能绕过这个重试间隔。

阵容数据来自固定 [OP.GG 阵容页](https://op.gg/tft/meta-trends/comps)，仍是全服、全段位、近 24 小时的同类阵容统计，热修未单独隔离。程序只接受与已知官方补丁相符的统计。官方已换版本而 OP.GG 尚未跟进时，旧列表可查阅，但不再作为当前补丁推荐。新补丁数据沿用兼容的结构时可自动接入；来源结构或代码格式改变仍需要维护，不保证永久免适配。

装备合成与排名刷新分开。当前保留 18.3 已核查的 137 件装备及 55 种配方；每日排名请求不会下载装备页，也不会改写配方日期或将旧表重标为新补丁。官方公告与基准版本/正文一致时，可继续使用配方，不因经过 72 小时单独失效。

[Riot Data Dragon 官方说明](https://developer.riotgames.com/docs/tft#data-dragon)列出的 TFT 物品字段是 ID、名称和图片，目前不足以自动核验完整配方。检测到新补丁或公告正文变更时，合成表显示“等待配方确认”并暂缓合成建议，保留原表供查阅。配方更新需要新的官方依据与核查后的资料；不能仅凭第三方排名变化或模型猜测覆盖原配方。此处对正文变更采取保守处理，也可能因非装备修改进入待核对状态。

公开更新不用模型、不发送游戏画面、不产生 DeepSeek 费用；付费 AI 跟进仍遵循已有单独授权和预算。

验证：离线测试覆盖跨日、6 小时检查、并发合并、缓存重启、断网重试、双排序变化、新补丁和官方/统计不一致。隐藏原生测试验证卡片变化、配方不被刷新覆盖、官方来源按钮及同日重启零网络请求。真实公开检查为首次 3 次请求、缓存重启 0 次，返回 50 套阵容及官方 18.3B。详见 [桌面验证](desktop-validation.md)。
