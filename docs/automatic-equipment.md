# 自动装备建议与阵容详情

自动跟进版：识别到唯一 TFT 游戏窗口后自动读取本机视频；如已配置并允许 DeepSeek 请求，会弹出本局确认，确认后开始持续识别。主窗口可从前四率前 4 套中选目标，装备建议随新鲜清单更新；2-1、3-2、4-2 阶段显示所选阵容的来源海克斯候选。实际三个选项尚未逐一识别，不能把来源顺序当成本局优先级。取消确认后仍可浏览本机画面及资料。

2026-09-24：Windows 包 `release/api-config-preview/Game Wingman-win32-x64/Game Wingman.exe`。先退出旧实例再启动，保留整个目录；共用原 profile 和累计 DeepSeek ¥10 账本。

英雄、装备与海克斯使用来源图标；合成方案显示“散件 + 散件 → 成装 → 推荐英雄”，站位格同时显示头像与配装，库存右下角为数量。悬停或键盘聚焦可看名称，图片不可用时保留名称。数量、缺件、来源、操作按钮仍用文字；没有改动合成优先级规则。

图标元数据来自对应 OP.GG 公开事实字段，主进程只读取限定 CDN 的 PNG/JPEG/WebP，不执行远程脚本。图片进入视野时按需加载，最多四路并发；成功文件缓存于 profile 的 `tft-icon-cache/`，有效七天，失败五分钟内不重复请求。旧版同赛季英雄缓存可补全头像，海克斯旧缓存下一次展开时升级。首次联网加载图片，不调用 AI、不发送游戏截图或密钥。

## 使用

1. 游戏窗口开始本机预览后，进入“资料与设置 → 装备合成”，点击“开启装备自动识别”，确认本次持续发送。每 5–15 秒提取己方剩余散件、已有成装及 HUD，自动更新合成建议。预览和查资料不会自行启用 AI。
2. 目标默认跟随当前推荐阵容（前四率排序），也可自己选定阵容。识别后的清单直接参与计算，无需再点击“确认采用”。手动纠正默认折叠；保存后暂时覆盖 AI 清单，“恢复自动识别”可取消覆盖。新开启跟进且确认成功后清除手动覆盖，取消会话则保留。
3. “现在优先合什么”只使用新鲜且完整的装备清单。数量变化后重新计算，扣除已有成装，每份散件仅分配一次。没有读清、超过 15 秒、停止或切换来源时，撤下当前建议。
4. “阵容配装、站位与海克斯”始终可作为目标参考，无需装备清单。列出各核心与其他棋子的目标装备和已核查配方；不能把目标参考当成材料已齐。普通散件不能合成的神器等单独标明。
5. 阵容卡片也可展开查看配装、参考站位与银/金/彩海克斯。阵容码仍由用户主动复制、自行粘贴。

## 来源与范围

[OP.GG 阵容页面](https://op.gg/tft/meta-trends/comps)现有 50 套变体，39 套含完整站位，11 套未提供坐标。原始坐标 x=1–7，y=4 为前排、y=1 为后排；按公开棋盘组件的坐标关系绘制，上方朝向对手。缺失、重叠、越界坐标不会被自动编造为站位。

海克斯读取同一页面使用的公开 `getAugment` 数据，参数仅为阵容 ID、补丁和中文语言。主进程先核对当前页面的版本及阵容，再读取页面引用的已知推荐模块，提取请求标识，不执行脚本。请求目标固定 OP.GG，无账号 Cookie、AI Key、截图或玩家信息。只保存候选 ID、名称、等级、可出现阶段及图标链接，不复制说明正文，不推断单个候选胜率。

展开时按阵容/补丁加载，重复请求合并，缓存存放在应用 profile 的 `tft-augment-cache/`；6 小时有效，重启可复用。失败 1 小时内抑制重复请求，同补丁 72 小时内旧缓存显示明确过期提示；更旧或跨补丁缓存不显示为当前候选。模块/接口结构改变时提示查阅来源，需要维护适配，不绕过网站限制。

站位随每天/6 小时的阵容统计更新。旧公共缓存缺少站位字段时会重新检查；AI 配置和预算不受影响。装备配方继续按[官方资料更新规则](daily-data-updates.md)独立审核，不随排行或海克斯刷新改变版本。

海克斯列表尚未匹配游戏当前给出的三个选项；站位也未根据对手实时重排。合成规则按阵容核心与来源配装顺序补缺，成装按全队总量扣除，未确定穿戴者，不评估装备转移、强化符文、即时战斗强度或全局最优。统计仍为全服/全段位/18.3，未隔离 18.3B，也未确认用户客户端版本。

## 验证

图标追加验证：53 项离线测试、类型检查及 `icon-preview` 包内隐藏原生回归通过。数量角标、名称回退、图标解码与浮窗边界正常；63 张公开来源图片读取成功。视觉证据 `artifacts/icon-packaged/` 使用来源图片与合成游戏状态，本轮没有付费 AI 或真实游戏准确率测试。

类型检查与 48 项离线测试通过（含保留的 6 项 STS1 测试）。隐藏 Electron 测试用假密钥、合成视频与模拟网络跑通：取消会话零请求；确认后自动识别“两弓一拳套”→轻语；下一帧已有轻语→红霸符；装备未知与停止后撤销合成提示，但目标配装保留。还验证棋盘方向、海克斯加载及 IPC 来源限制。本轮没有付费 AI 请求，也没有把合成测试当成真实 TFT 装备识别质量验证。

实际公开数据读取已通过：主宰艾希的 17 个海克斯候选（银 1、金 11、彩 5），首次 3 次公开 HTTP 请求，带补丁和读取时间缓存。真实游戏准确率、对手战术适应、海克斯三选一决策及 macOS 本轮复测仍未完成。
