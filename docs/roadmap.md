# Roadmap


2026-09-24：已在 Windows 接续，本机开发版与便携包合成窗口测试通过，真实 TFT 验证待完成。此文档不设未经验证的交付日期。

| 阶段 | 当前状态 | 验收条件 |
| --- | --- | --- |
| 桌面基础 | 已实现，macOS / Windows 合成测试通过 | 主窗口、浮窗、指定窗口读取、停止与恢复 |
| Windows 验证 | 开发版 / 便携包合成测试通过，游戏实测待完成 | 手动 TFT 窗口 / 无边框测试，记录环境与限制 |
| 三家 API | 真实文本 / 合成图测试通过，默认 DeepSeek；见 API 文档 | 持续验证可用模型、真实画面准确性、延迟和成本 |
| 应用内模型配置 | 已实现并验证 | 简洁设置、系统加密凭据、固定端点、手动发送确认 |
| 识别与校正 | 单帧提取、unknown、实体映射及人工校正已接通 | 真实 TFT 截图质量评估；不把格式检查当作事实验证 |
| 视频持续跟进 | 已接通视频预览、5–15 秒识别、变化记录及跨重启 ¥10 DeepSeek 预算；模拟测试通过 | 用户首次单局测试，核对真实字段、响应耗时、费用与停止行为 |
| 阵容与装备参考 | OP.GG 50 套变体、配装/站位/海克斯、137 件装备/55 配方已接入 | 多来源核对与真实游戏验证继续进行 |
| 动态建议闭环 | 待实现 | 低频触发、取消旧任务、来源绑定解释、成本与延迟记录 |
| 更广泛试用 | 待实现 | 平台支持矩阵、可复现安装、反馈修复；完成代码许可证决策 |
| 后续游戏 | 独立研究，不属于本次 TFT 交付 | 按游戏单独验证规则、资料来源和桌面适配 |

保持原则：简洁的桌面 UI；美服 TFT 数据边界；不复制参考项目 UI；不隐藏试用品和封号风险；构建、自动测试、真实游戏验证和公开发布分别记录。
