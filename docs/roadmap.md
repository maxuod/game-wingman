# Roadmap

2026-09-24：暂停在公开源码交接点，接下来在 Windows 继续。此文档不设未经验证的交付日期。

| 阶段 | 当前状态 | 验收条件 |
| --- | --- | --- |
| 桌面基础 | 已实现，macOS 合成测试通过 | 主窗口、浮窗、指定窗口读取、停止与恢复 |
| Windows 验证 | 下一步 | 合成测试、手动 TFT 窗口 / 无边框测试，记录环境与限制 |
| 三家 API | 文本适配与离线测试完成，真实调用待验证 | 用自有密钥验证 MiniMax / DeepSeek / Gemini 并记录实际模型、耗时和用量 |
| 应用内模型配置 | 待实现 | 简洁设置、系统凭据存储、明确提供方、用户主动启用发送 |
| 识别与校正 | 待实现 | 指定截图、实体 ID、unknown、人工校正；不把推测当作观测 |
| 攻略检索 | 待实现 | 少量自有已审核条目、来源、赛季 / 补丁过滤、无匹配降级 |
| 动态建议闭环 | 待实现 | 低频触发、取消旧任务、来源绑定解释、成本与延迟记录 |
| 更广泛试用 | 待实现 | 平台支持矩阵、可复现安装、反馈修复；完成代码许可证决策 |
| 第二款游戏 | 待选 | 独立游戏适配器，验证捕获 / 检索 / 浮窗复用 |

保持原则：简洁的桌面 UI；美服 TFT 数据边界；不复制参考项目 UI；不隐藏试用品和封号风险；构建、自动测试、真实游戏验证和公开发布分别记录。
