# 试用说明

更新日期：2026-09-24。当前为桌面试用版 0.1。已有 Electron 主窗口、独立浮窗和画面输入，尚未接入 OCR、AI 识别与战术攻略。macOS 原生技术测试及构建记录见 [桌面验证记录](desktop-validation.md)。

## 项目用途

Game Wingman 是 AI 游戏攻略助手的实验样品，以 TFT 为首个适配案例，验证屏幕读取、攻略检索、AI 解释和桌面浮窗。计划通过 GitHub 获取反馈，为后续游戏产品提供可复用模块。

## 准确性与已知限制

- 当前只读取 / 预览画面，不识别英雄或生成建议。未来识别结果仍需校正，AI 不承诺提升胜率或段位。
- “美服资料”是 Set 18 英雄与羁绊的英文名称字典，包含部分形态条目，不是攻略、胜率榜或实时美服统计。资源版本不等于 TFT 补丁，热修覆盖未确认。
- macOS 已用独立合成窗口验证读取 / 暂停 / 关闭窗口，不代表 TFT 实际对局兼容。Windows、独占全屏、多显示器、缩放和低性能机器还需实测。
- 点击穿透已调用系统窗口接口，不能据此认定软件不会被游戏或反作弊系统限制。
- 关闭或暂停后保留最后一帧预览，并标注时间和“已暂停”；不会把旧帧当作继续读取中的画面。最小化或遮挡时的行为取决于系统，发现画面异常时可暂停或导入截图。

## 安装与操作

1. macOS Apple Silicon：打开 `release/Game Wingman-darwin-arm64/Game Wingman.app`。这是未公证的本地试用应用。也可按 README 通过 `npm ci`、`npm start` 从源代码启动。Windows 构建目录中的所有文件需要保留在一起，运行其中的 `Game Wingman.exe`；Windows 尚未实机验证。
2. 点击“选择窗口”，选择游戏窗口，再点击“开始读取”。系统需要屏幕权限时由用户决定是否授权；macOS 授权后可能需要退出并重新打开应用。不会读取整个桌面，也不采集音频。
3. 查看主窗口预览，确认选择正确。“暂停读取”会停止采集；“导入截图”支持 PNG、JPG、WebP，文件不超过 20 MB。
4. 点击“显示浮窗”。拖动浮窗顶栏调整位置，`−` 收起，`×` 隐藏。浮窗尚无 AI 建议时明确显示等待状态。
5. 如需查询名称，打开“资料与设置 → 美服资料”，主动同步后用英文名称搜索，点击条目固定到浮窗。选择“取消固定”恢复画面状态提示。
6. “浮窗设置”可调透明度、点击穿透、恢复位置。macOS 使用 `⌘ Shift O` 显示 / 隐藏、`⌘ Shift I` 切换点击穿透；Windows 使用 `Ctrl` 替代 `⌘`。快捷键被其他软件占用时不启用穿透，主窗口和菜单栏 / 托盘仍可恢复操作。
7. macOS 关闭主窗口会停止读取并隐藏浮窗，应用保留在菜单栏；通过菜单栏退出或 `⌘ Q` 完全退出。Windows 关闭主窗口即退出。

## 当前数据处理

仅处理用户选择的窗口或图片。视频流和预览截图留在应用内存，应用不保存或上传屏幕内容；停止采集后保留最后一帧用于查看，切换来源 / 关闭主窗口 / 退出会清除。应用不读取游戏内存，不注入进程，不自动控制游戏，没有账户登录或模型密钥。

应用只在点击“同步资料”时访问 Riot Data Dragon 的固定 HTTPS 地址；名称字典缓存保存在系统应用数据目录下的 `Game Wingman/tft-na-catalog.json`。没有截图遥测或自动反馈。系统权限管理、崩溃日志和虚拟内存属于操作系统行为，不将“应用不主动保存截图”等同于整个系统绝不落盘。

未来接入云端模型前，必须明确提供方、发送范围与费用，并由用户主动启用；当前桌面界面没有云端模型请求。另有可选开发 CLI 文本测试：只有在本地配置密钥、主动启用并添加 `--probe` 时才向所选提供方发送固定测试文字，可能收费；不发送截图，见 [API 提供方说明](api-providers.md)。

不要求提供游戏密码或账号凭据。反馈由用户主动提交，不自动上传屏幕或对局记录；GitHub Issue 可能公开可见，请删除截图和文字中的玩家标识、聊天、通知、API 密钥及其他个人信息。
