## 项目用途

Game Wingman 是 AI 游戏攻略助手的实验样品，以 TFT 为首个适配案例，验证屏幕读取、攻略检索、AI 解释和桌面浮窗。计划通过 GitHub 获取反馈，为后续游戏产品提供可复用模块。

## 准确性与已知限制

- 当前识别可见字段、名称及己方装备，在单独确认后持续跟进；装备需核对。合成建议按来源配装补缺，不评估对手、强化符文和即时战斗强度，不承诺提升胜率或段位。
- “美服资料”是 Set 18 英雄与羁绊的英文名称字典，包含部分形态条目，不是攻略、胜率榜或实时美服统计。资源版本不等于 TFT 补丁，热修覆盖未确认。
- macOS 已用独立合成窗口验证读取 / 暂停 / 关闭窗口，不代表 TFT 实际对局兼容。Windows、独占全屏、多显示器、缩放和低性能机器还需实测。
- 点击穿透已调用系统窗口接口，不能据此认定软件不会被游戏或反作弊系统限制。
- 关闭或暂停后保留最后一帧预览，并标注时间和“已暂停”；不会把旧帧当作继续读取中的画面。最小化或遮挡时的行为取决于系统，发现画面异常时可暂停或导入截图。

## 安装与操作

1. macOS Apple Silicon：打开 `release/Game Wingman-darwin-arm64/Game Wingman.app`，这是未公证的本地应用；AI 更新尚未在 macOS 重新验证。Windows 最新为 `release/equipment-preview/Game Wingman-win32-x64/Game Wingman.exe`，沿用 DeepSeek ¥10 预算，保留整个目录，先退出旧版。也可按 README 从源码启动。
2. 点击“选择窗口”，选择游戏窗口，再点击“开始读取”。系统需要屏幕权限时由用户决定是否授权；macOS 授权后可能需要退出并重新打开应用。不会读取整个桌面，也不采集音频。
3. 查看主窗口预览，确认选择正确。“暂停读取”会停止采集；“导入截图”支持 PNG、JPG、WebP，文件不超过 20 MB。
4. 点击“显示浮窗”。拖动浮窗顶栏调整位置，`−` 收起，`×` 隐藏。浮窗尚无 AI 建议时明确显示等待状态。
5. 如需查询名称，打开“资料与设置 → 美服资料”，主动同步后用英文名称搜索，点击条目固定到浮窗。选择“取消固定”恢复画面状态提示。
6. “浮窗设置”可调透明度、点击穿透、恢复位置。macOS 使用 `⌘ Shift O` 显示 / 隐藏、`⌘ Shift I` 切换点击穿透；Windows 使用 `Ctrl` 替代 `⌘`。快捷键被其他软件占用时不启用穿透，主窗口和菜单栏 / 托盘仍可恢复操作。
7. macOS 关闭主窗口会停止读取并隐藏浮窗，应用保留在菜单栏；通过菜单栏退出或 `⌘ Q` 完全退出。Windows 关闭主窗口即退出。

## 当前数据处理

仅处理用户选择的窗口或图片。预览留在本机内存，不自动上传或保存；暂停保留最后一帧，切换来源 / 关闭主窗口 / 退出会清除。应用不读取游戏内存、不注入进程、不自动控制游戏。模型凭据由用户导入并以系统加密方式保存在本机。

点击“同步资料”访问 Riot Data Dragon 固定 HTTPS 地址，字典缓存位于系统应用数据目录 `Game Wingman/tft-na-catalog.json`。手动 AI 请求只发送到所选提供方，没有截图遥测或自动反馈。系统缓存、崩溃日志和虚拟内存不属于应用主动保存截图的范围。

在“资料与设置 → AI 识别”配置并启用手动请求后，可点击“识别这一帧”。确认框列明提供方、模型、端点及画面时间；确认后只发送预览中的一张截图，可能产生费用，取消则不发送。结果需要人工核对，空值保留未知，字段标注画面时间，装备合成参考需要新鲜或手动确认的清单。没有自动重试或跨提供方回退。开发 CLI `--probe` 仍仅发送固定文字，详见 [API 提供方说明](api-providers.md)。

“开始本次跟进”另行确认后会持续发送所选窗口的抽样图片，每 5–15 秒一次，浮窗显示字段与画面时间。暂停、换窗、失败或达到限制即停止。首次测试固定 DeepSeek，桌面请求共享跨重启累计 ¥10 预算；账本保存费用用量和时延，不保存截图或昵称。详细步骤、保守预留与未确认费用处理见[首次 DeepSeek 测试](deepseek-first-test.md)。

不要求提供游戏密码或账号凭据。反馈由用户主动提交，不自动上传屏幕或对局记录；GitHub Issue 可能公开可见，请删除截图和文字中的玩家标识、聊天、通知、API 密钥及其他个人信息。
