## 项目用途

Game Wingman 是 AI 游戏攻略助手的实验样品，以 TFT 为首个适配案例，验证屏幕读取、攻略检索、AI 解释和桌面浮窗。计划通过 GitHub 获取反馈，为后续游戏产品提供可复用模块。

## 准确性与已知限制

- 当前识别可见字段、名称及己方装备，在单独确认后持续跟进；装备需核对。合成建议按来源配装补缺，不评估对手、强化符文和即时战斗强度，不承诺提升胜率或段位。
- 后台名称字典仅辅助实体匹配，不参与战术推荐；资源版本不等于 TFT 补丁，热修覆盖未确认。
- macOS 已用独立合成窗口验证读取 / 暂停 / 关闭窗口，不代表 TFT 实际对局兼容。Windows、独占全屏、多显示器、缩放和低性能机器还需实测。
- 点击穿透已调用系统窗口接口，不能据此认定软件不会被游戏或反作弊系统限制。
- 关闭或暂停后保留最后一帧预览，并标注时间和“已暂停”；不会把旧帧当作继续读取中的画面。最小化或遮挡时的行为取决于系统，发现画面异常时可暂停或导入截图。

## 安装与操作

1. Windows 打开 `release/advice-first-preview/Game Wingman-win32-x64/Game Wingman.exe`，保留整个目录并先退出旧版；macOS 可按 README 从源码构建。新包沿用原来的 DeepSeek ¥10 账本。
2. 在首页四套阵容里选一套。程序识别到唯一 TFT 窗口后自动读取；未找到时用“手动选窗”。已配置并启用 DeepSeek 时，持续识别还需确认本次发送。
3. 看“本局怎么打”：下一步、当前装备合成和对应阶段的海克斯来源候选会随新画面更新。读不清或数据过期时会显示等待；海克斯需与本局实际选项核对。可点“查看配装和站位”或“复制阵容码”。
4. “查看游戏画面与手动操作”默认收起；展开后可检查视频、识别单帧或导入 PNG/JPG/WebP 截图（不超过 20 MB）。暂停读取会停止采集。
5. 浮窗默认置顶，跟随所选阵容；顶栏可拖动，`−` 收起。需要隐藏时用主窗口或托盘。设置中的“浮窗设置”可调透明度和点击穿透。
6. macOS 使用 `⌘ Shift O` 显示 / 隐藏浮窗、`⌘ Shift I` 切换穿透；Windows 使用 `Ctrl` 替代 `⌘`。快捷键被占用时主窗口和菜单栏 / 托盘仍可恢复操作。

## 当前数据处理

仅处理用户选择的窗口或图片。预览留在本机内存，不自动上传或保存；暂停保留最后一帧，切换来源 / 关闭主窗口 / 退出会清除。应用不读取游戏内存、不注入进程、不自动控制游戏。模型凭据由用户导入并以系统加密方式保存在本机。

名称字典如已有缓存，仅用于后台名称匹配，主界面没有独立查询入口。手动 AI 请求只发送到所选提供方，没有截图遥测或自动反馈。系统缓存、崩溃日志和虚拟内存不属于应用主动保存截图的范围。

在“设置 → AI 识别”配置并启用手动请求后，可点击“识别这一帧”。确认框列明提供方、模型、端点及画面时间；确认后只发送预览中的一张截图，可能产生费用，取消则不发送。结果需要人工核对，空值保留未知，字段标注画面时间，装备合成参考需要新鲜或手动确认的清单。没有自动重试或跨提供方回退。开发 CLI `--probe` 仍仅发送固定文字，详见 [API 提供方说明](api-providers.md)。

“开始本次跟进”另行确认后会持续发送所选窗口的抽样图片，每 5–15 秒一次，浮窗显示字段与画面时间。暂停、换窗、失败或达到限制即停止。首次测试固定 DeepSeek，桌面请求共享跨重启累计 ¥10 预算；账本保存费用用量和时延，不保存截图或昵称。详细步骤、保守预留与未确认费用处理见[首次 DeepSeek 测试](deepseek-first-test.md)。

不要求提供游戏密码或账号凭据。反馈由用户主动提交，不自动上传屏幕或对局记录；GitHub Issue 可能公开可见，请删除截图和文字中的玩家标识、聊天、通知、API 密钥及其他个人信息。
