# 30 分钟实时视频跟进：API 费用估算

核查日期：2026-09-24。以下是预算模型，未执行 30 分钟真实游戏计费测试，不是账单或承诺上限。

## 计费范围和假设

- 本机连续播放用户选定窗口的视频流；付费模型接收抽取的单张图片，不按本地播放帧率计费。
- 每次假设 1,500 个计费输入 token（包含图片与提示词），200 个计费输出 token（包含可能计费的思考）。实际图片 token 因提供方和分辨率不同而变化。
- 单次输入只有当前画面和短提示词，不重复携带完整对局历史；输出只有可见字段，不含攻略检索、复杂战术长文、语音或联网搜索。
- 按单家 API、标准按量价、无缓存优惠、无免费额度、无重试计算。Gemini 仅为方便预算按 $1 = ¥7 换算，不是实时报价。
- 用户随后授权首次 DeepSeek 测试上限 ¥10。当前会话上限已扩展到 60 分钟 / 720 次，以覆盖一局约 30 分钟游戏；增加跨会话/重启累计预算，详见[金额保护](deepseek-first-test.md)。本页场景估算本身仍不是实际账单。

## 已核对的单价

- DeepSeek Flash：每百万输入 token，缓存未命中闲时 ¥1、峰时 ¥2；每百万输出 token 闲时 ¥4、峰时 ¥8。来源：[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/?article_id=article_1779470751466_8)。
- MiniMax M3 国内：上下文不超过 512K、标准档、现行五折价格为每百万输入 ¥2.1 / 输出 ¥8.4。来源：[国内 API 价格页](https://platform.minimax.cn/subscribe/token-plan?tab=api-enterprise)，通过浏览器读取其动态表格。
- Gemini 3.5 Flash-Lite：每百万输入 $0.30 / 输出 $2.50，输出价格包含思考 token。来源：[Google 官方价格](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite)。

## 套餐和误差

MiniMax Token Plan 与按量账单不同：套餐内调用消耗共享额度；达到窗口上限后，若存在已购积分，官方说明可能自动使用积分补充。未核查用户账户的当前套餐、余额、剩余配额或积分，因此不能由公开单价推断实际扣款。[套餐规则](https://platform.minimax.cn/subscribe/token-plan)

本项目先前的清晰合成图每次实际输入 token 为 DeepSeek 307、MiniMax 648、Gemini 1,179；可见输出分别约 26–33、33、56。这些样本不代表真实 TFT 棋盘，且历史 Gemini 记录仅取 candidatesTokenCount，未单独记录 thoughtsTokenCount，不能作为完整思考计费记录。原数据见 [历史测量](data/ai-benchmark-2026-09-24.json)。

1,500 / 200 是规划场景而非上界。分辨率、实体数量、思考输出、失败是否计费，以及后续追加战术任务都会改变实际费用。DeepSeek 每局约 ¥2 仅作短字段识别预算参考。新测试版另有独立的 ¥10 金额保护，通过发送前保守预留执行，不把本页平均场景当作安全上界。
